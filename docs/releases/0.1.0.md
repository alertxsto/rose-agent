# Rose Agent 0.1.0

Native Rational Rose class-model editor with explicitly reviewed AI chat.
This release is **prerelease** while actual Windows 8.1 guest execution and fresh
native-Rose acceptance of the newest exports remain unverified.

## Downloads

- Linux x86-64: `.deb`, `.rpm`, relocatable `.tar.gz`; bundled Qt6.8.3,
  Ubuntu22.04/glibc2.35 or newer baseline. Install package dependencies through
  apt/dnf; the portable archive needs the documented system libraries.
- Windows10 (1809+) / 11 x64: `RoseAgent-0.1.0-windows-x64-setup.exe` and
  `RoseAgent-0.1.0-windows-x64-portable.zip`.
- Windows8.1-targeted x86: `RoseAgent-0.1.0-windows-x86-setup.exe` and
  `RoseAgent-0.1.0-windows-x86-portable.zip`. This is a real Qt5.15.18/v142 build,
  not a renamed Qt6/x64 executable. It uses Schannel, app-local VC14214.29 CRT
  and SDK19041 Universal CRT; it does not install the current incompatible
  VC143 runtime or bundle obsolete OpenSSL1.1.
- `SHA256SUMS.txt`, `release-manifest.json`, public application source ZIP/tar.gz,
  and the exact corresponding Qt5/Qt6 source archives.

All binaries are **unsigned**. Compare downloaded hashes against SHA256SUMS;
checksums do not replace a publisher signature. Keep the complete portable
runtime together. Installers are per-user, do not seize `.mdl` associations,
and uninstall only their exact packaged files rather than deleting user models
or credentials.

## Included functionality

- Native Petal44 default and explicit Petal50 profiles; existing versions are
  preserved, never downgraded by a header edit.
- Class/package/member authoring, binary associations, inheritance and native
  class-diagram layouts; unsupported imported source remains preserved.
- Model browser, native canvas, manual editing, undo/redo, guarded import and
  source-preserving Save/Save As. Manual editing works offline.
- OpenAI-compatible Base URL/key setup, discovered models, honest provider
  context metadata, OS-only credentials and prompt/PNG/JPEG/WebP input.
- Photo-aware chatbot history, plain-text selectable messages, Send/Stop,
  Enter/Shift+Enter, attachments, responsive wrapping/scrolling, separate activity
  and complete exact review. Apply changes memory; Save is always separate.
- Deterministic native view dependency ordering and faithful explicit endpoints.
  Custom routes use native symbol centers, not top-left coordinates.

## Release gates and limits

The publishing workflow requires Linux Qt6, Linux Qt5 and both Windows builds to
pass their behavioral suites. Actual deployed-runtime probes exercise native
review/reject/wrong-digest denial, exact apply, no implicit save, separate Save,
independent reopen, the real GUI canvas, PNG/JPEG/WebP codecs and certificate-
validated HTTPS. Linux additionally stages/relocates the bundle and installs/
  uninstalls the DEB. A pinned Fedora44 container installs, exercises and removes
  the actual RPM. Windows installers are installed and run, then uninstalled
  while verifying that an additional native user model remains byte-identical.

The x86 artifact gate checks every shipped PE's architecture, subsystem floor,
required runtime closure and known post-Windows8.1 static API imports. Hosted
WindowsServer2022 execution is **not** a Windows8.1 guest test. This boundary is
recorded in release-manifest.json. Windows8.1 is end-of-life; application support
cannot restore its security updates or fix an obsolete trust/TLS configuration.
No TLS certificate verification bypass is provided.

Earlier exact Petal44 exports displayed in Rational Rose2000e; that release
rejected Petal50. Neither internal native reopen nor historical acceptance
certifies every new export, every Rose edition, or 1:1 feature parity.
